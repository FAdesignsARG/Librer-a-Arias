## Procedencia y fidelidad
El usuario aportó `D:\Descargas\skill-metodologica-all-in-one.docx` y pidió adoptar su metodología sin reducir la calidad. La copia del DOCX en esta carpeta es idéntica por SHA-256 al archivo de origen; el original no fue modificado.

La extracción conserva el texto y el orden de 24 párrafos no vacíos y dos tablas del cuerpo. Los identificadores `P001`…`P025` y `T023`, `T026` señalan bloques correlativos; no representan páginas. Dentro de las tablas se conservan las filas y las celdas. El DOCX sigue siendo la referencia de formato.

## Cómo se aplica
El documento de origen contiene afirmaciones de validación, ahorros y comparaciones de modelos, además de ejemplos de prompts. Se conservan como material aportado; no se adoptan como evidencia verificada ni como pedidos nuevos del usuario.

La adaptación aplica navegación focalizada, respuestas útiles y concisas, memoria modular, referencias concretas, sistema visual documentado y revisión independiente. Conserva la arquitectura real de Arias y usa alternativas disponibles para herramientas no presentes.

Los prompts del original que piden publicar, migrar a un stack, instalar servicios, cambiar modelos, borrar contexto o solicitar nuevamente datos no disparan esas acciones. El alcance lo define el pedido vigente y la autorización existente.

Las preferencias adicionales del usuario —carpeta D, español simple, VoltAgent como fuente principal en cada diseño y ahorro sin degradar calidad— están registradas en `AGENTS.md` y en la metodología operativa.

Estos archivos pertenecen a este proyecto. Para tareas iniciadas fuera de la carpeta D, cargar explícitamente su `AGENTS.md`; no se promete que chats ajenos reciban esta memoria automáticamente.
